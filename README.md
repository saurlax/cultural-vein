# 文脉溯源

“文脉溯源”是一个面向上海图书馆开放数据竞赛的 Web 交互项目。项目以“文脉 = 水脉”的黄河长卷隐喻为核心，把典籍之间的引用、注疏、传承与影响关系组织成一条可探索的三维知识长河，并提供典籍钻入后的地理传播、人物关系、版本流变、关联时间线与文本溯源体验。

## 项目定位

本仓库当前提供一套可运行、可演示、可继续扩展的参赛作品实现，包含：

- 宏观层：整页黄河长卷、时间轴推进、概念搜索、类别筛选、来源河册
- 中观层：地理传播、人物关系、版本流变、关联时间线
- 微观层：文本对读、证据切换、溯源链路、下游影响追踪
- 真实数据层：纪传人物、馆藏条目、活动资料、借阅流通、专题文献、城市影像、诗学图谱与近现代报刊等多类来源

## 当前实现状态

当前版本重点完成了沉浸式主场景与多层级典籍探索的主体实现：

- 以核心典籍主干构建可交互的“黄河文脉长卷”
- 当前已覆盖《诗经》《尚书》《周易》《论语》《礼记》《孝经》《大学》《中庸》《孟子》《春秋左传》《史记》《论语集注》《四书章句集注》《资治通鉴》《日知录》《人间词话》等主干节点
- 使用本地生成数据替代大段前端硬编码明细
- 将真实数据资料持续并入人物、时间线、机构来源模块
- 已补入河流镜头俯冲/拉回，以及文本溯源到河流视图的宏微联动
- 已补入概念搜索 API、概念联想与结果命中排序
- 已形成单书级的来源证据板、来源证据总表与多来源线索汇总
- 首页已经收口为整页河流场景，控制浮层显著减重，形成更适合现场展示的“巡河 -> 入卷 -> 归河 -> 切来源”主链路
- 来源河册已按时代优先排序，并以“红色支流 / 诗学支流 / 馆藏支流 / 城市影像 / 公共流通”等主题标签统一呈现
- 来源河册的 `theme / era / filterOptions` 现已由后端 payload 直接结构化输出，前端筛选不再主要依赖名称推断
- 首页主控现已收口为更少的卷边面板与移动端单入口，不再以多浮窗堆叠信息
- 整体视觉已统一到黄河泥金与典籍纸卷质感，首页与河面都采用全中文叙事
- 形成统一的本地 API 与前端消费结构

当前仍可继续扩展的部分主要有：

- 更大规模书目关系自动清洗与导入
- 真正的图数据库 / 搜索引擎后端
- 更完整的引文自动检测与语义关联计算
- 更大规模的正式参赛书目扩充

## 运行方式

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000` 查看应用。

如需单独启动轻量后端骨架：

```bash
pnpm backend:dev
```

默认监听 `http://localhost:4318`，当前可提供：

- `/health`
- `/graph`
- `/books/:slug`
- `/insights`
- `/source-atlas`
- `/source-atlas/:id`
- `/search?q=关键词`

其中 `/source-atlas` 现支持：

- `q=关键词`
- `era=先秦|两汉|魏晋|隋唐|宋元|明清|近现代`
- `theme=人物支流|红色支流|馆藏支流|诗学支流|公共流通|城市现场|城市影像|艺术图像|近现代文献|近现代支流|来源支流`
- `limit=数量`

来源河册条目当前已内置 `relatedBookSlugs`，用于把每股真实来源更明确地牵到对应河段，而不再主要依赖前端按名称推测。
`/source-atlas` 当前也会直接返回结构化 `theme`、`era` 与来源筛选统计，便于前端和独立后端共用同一套来源筛选口径。
前端来源河册面板现在也会直接列出这股支流牵出的典籍，可从来源说明一键顺流入卷。

## 数据管线

项目当前采用“离线导出 + 前端消费”的轻量数据管线：

1. 原始数据放在 `/data`
2. Python 脚本 `scripts/export_real_dataset.py` 从可稳定利用的数据包中抽取资料
3. 输出到 `src/data/generated/real-supplements.json`
4. `src/data/river-dataset.ts` 负责把生成数据与运行时增强逻辑合并成前端图谱

重新生成资料数据：

```bash
@'
from scripts.export_real_dataset import main
main()
'@ | python -
```

## 参赛展示路径

推荐展示逻辑：

1. 直接从首页进入“黄河文脉长卷”，展示时代推进、主河道与支流结构
2. 顺河点入《论语》《周易》或《四书章句集注》，进入单书文卷
3. 展示传播、人物、版本、时间线与单书来源证据板
4. 切到文本溯源，说明显式引用、语义关联与下游影响
5. 归河后切换来源河册，展示真实来源如何反向驱动河面焦点
