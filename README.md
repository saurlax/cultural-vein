# 文脉溯源

“文脉溯源”是一个面向上海图书馆开放数据竞赛的 Web 交互作品原型。项目以“文脉 = 水脉”的河流隐喻为核心，把典籍之间的引用、注疏、传承与影响关系组织成一条可探索的三维知识长河，并提供典籍钻入后的地理传播、人物关系、版本流变、关联时间线与文本溯源体验。

## 项目定位

本仓库当前已经不只是静态 demo，而是一个可演示、可扩展的参赛作品骨架，包含：

- 宏观层：三维河流总览、时间轴推进、概念搜索、类别筛选
- 中观层：地理传播、人物关系、版本流变、关联时间线
- 微观层：文本对读、证据切换、溯源链路、下游影响追踪
- 真实数据层：CBDB 人物传记、人物活动地点、人物活动时间线线索、上海图书馆活动样本、南京图书馆图像资源样本、复旦大学图书馆馆藏样例

## 当前实现状态

当前版本重点完成了“可答辩演示”的第一阶段实现：

- 以示范域典籍构建可交互的“文脉河流”
- 使用本地生成数据替代大段前端硬编码明细
- 将真实数据样本持续并入人物、时间线、机构来源模块
- 形成统一的本地 API 与前端消费结构

仍未完全实现的部分主要有：

- 更大规模书目关系自动清洗与导入
- 真正的图数据库 / 搜索引擎后端
- 更完整的引文自动检测与语义关联计算
- 更大规模的正式参赛示范域扩充

## 数据管线

项目当前采用“离线导出 + 前端消费”的轻量数据管线：

1. 原始数据放在 `/data`
2. Python 脚本 `scripts/export_real_dataset.py` 从可稳定利用的数据包中抽取样本
3. 输出到 `src/data/generated/real-supplements.json`
4. `src/data/demo-graph.ts` 负责把生成数据与运行时增强逻辑合并成前端图谱

重新生成样本数据：

```bash
@'
from scripts.export_real_dataset import main
main()
'@ | python -
```

## 目录结构

```text
src/
  app/
    api/                 # 本地 API
  components/            # 首页、河流场景、典籍探索面板
  data/
    generated/           # 由脚本生成的真实样本数据
  store/                 # Zustand 状态
  types/                 # 领域模型
scripts/
  export_real_dataset.py # 真实样本导出脚本
data/                    # 用户已下载的竞赛原始数据
tmp_cbdb/                # 解压后的 CBDB 数据库
tmp_generated/           # 中间文件
```

## 参赛展示口径

推荐演示逻辑：

1. 先从首页展示“文脉河流”与时代推进
2. 选择《诗经》或《四书章句集注》进入中观层
3. 展示传播、人物、版本、时间线的四类关联叙事
4. 切到文本溯源，说明显式引用 / 语义关联 / 下游影响
5. 强调真实数据已接入的部分：CBDB、上图、南京图书馆、复旦图书馆

更完整的现场演示脚本、评审问答预案和提交前检查清单见 [DELIVERY.md](./DELIVERY.md)。
